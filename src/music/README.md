## 想自己加音乐

1. 把音频文件（`.ogg` / `.mp3`）放进本目录
2. 打开 `src/ui/audio.js`，在顶部的播放列表数组里加上**完全一致的文件名**

播放列表在 `src/ui/audio.js` 顶部，文件名必须逐字符匹配（包括空格和扩展名）。找不到文件时游戏会**静默跳过那一首**，不会报错崩溃，所以漏加文件名只会表现为"少了一首曲子"。
